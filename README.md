# Brickstone Realty Group

**Affordable NYC Rental Apartments — No Hidden Broker Fees**

> Real Homes. Real Prices. Real New York.

A modern, tenant-first property listings website showcasing rental apartments across all five New York City boroughs. Built to help renters find their next home quickly and confidently — without the confusion of hidden fees or broker markups.

🌐 **Live site:** [brickstonerealtygroups.com](https://www.brickstonerealtygroups.com)

---

## About

Brickstone Realty Group is a tenant-first rental agency operating across every NYC borough. This website serves as the primary digital front for attracting prospective tenants, showcasing available listings, and converting visitors into qualified leads via a direct contact form.

The site is fully **FARE Act (2025) compliant** — tenants are never charged broker fees.

## Site Features

- **Photo carousel** on every listing — swipe through Living Room, Bedroom, Kitchen, and Bathroom shots
- **Video tours** available on select properties
- **Fullscreen photo lightbox** — StreetEasy-style image viewer
- **Borough filter** — instantly narrow listings by Manhattan, Brooklyn, Queens, The Bronx, or Staten Island
- **How It Works** section — 3-step process (Share Needs → Schedule Tour → Sign & Move In)
- **Neighborhoods covered** — detailed borough-by-borough breakdown
- **Contact form** — direct enquiry with move-in date and budget fields
- **PWA-ready** — installable on mobile with offline fallback page
- **Fully responsive** — optimised for mobile, tablet, and desktop
- **FARE Act badge** — builds immediate trust with prospective tenants

## Getting Started

No build step required — this is a pure static site.

```bash
# Clone the repo
git clone https://github.com/devola11/Brickstone-Realty-Group.git
cd Brickstone-Realty-Group

# Serve locally (any static server works)
npx serve .
# or
python -m http.server 3000
```

Then open **http://localhost:3000** in your browser.
